# Murphy

Murphy is an offline music player for Android. It plays the music files already on your phone:
no account, no ads, no streaming.

This repository holds Murphy's **downloads only**. Murphy's source code is private.

**[⬇ Download the latest version](https://github.com/mannydiwa/murphy/releases/latest)**

## Highlights
- Fast library: songs, albums, artists, playlists, genres and folders, with typo-tolerant search.
- Now Playing with lyrics, sleep timer, A–B loop and gapless playback.
- Audio effects (pitch, speed, reverb, echo, filters, 8D) and a 10-band equalizer.
- Artist themes and your own custom themes.
- Listening stats, daily mixes and a yearly recap.
- Home-screen widget, Quick Settings tile and Android Auto.

## Requirements
Android 7.0 or newer.

## Install
1. Open the [latest release](https://github.com/mannydiwa/murphy/releases/latest) on your phone and
   download `Murphy-vX.Y.Z-release.apk`.
2. Open the downloaded file. The first time, Android asks you to allow installs from your browser
   or file app; allow it, then tap **Install**.
3. **Google Play Protect** may say it hasn't seen Murphy before, because Murphy isn't on the Play
   Store. Tap **More details › Install without scanning**, or **Scan app** if you'd like Google to
   check it first.

To check a download, compare its SHA-256 with the `.sha256` file published next to it.

## Updates
Murphy checks this page about once a day and offers new versions itself: **Update now** downloads
the new version, checks it, and Android asks you to confirm. The first time, Android asks you to
let Murphy install apps (**Allow from this source**).

- Check any time: **Settings › About Murphy › Check for updates**.
- Turn the daily check off: **Settings › Behavior › Check for updates automatically**.
- Updating keeps your library, playlists and settings.

Murphy only goes online to check this page and download updates. Nothing about your music or how
you use Murphy is sent anywhere.

## Going back to an older version
The three most recent versions stay on the [releases page](https://github.com/mannydiwa/murphy/releases).
If a new version has a serious problem, a fixed version usually follows quickly, and waiting for it
is the safest way back. If you can't wait:

1. **Back up first: Settings › Library › Back up library.** Uninstalling deletes Murphy's
   playlists, likes, play history and settings. Your music files themselves are not touched.
2. Uninstall Murphy. Android doesn't let an older version install over a newer one.
3. Install the older APK from the releases page, then use **Settings › Library › Restore from
   backup**.

Every Murphy release is signed with the same key, so only genuine Murphy versions can update it.
If Android says the app "conflicts with an existing package", the APK isn't a Murphy release from
this page.

## Reporting a problem
Open an [issue](https://github.com/mannydiwa/murphy/issues) with your Murphy version (Settings ›
About Murphy › Version & build › Copy build info), your phone model and Android version, and what
happened.
